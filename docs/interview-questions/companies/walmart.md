## Interview Rounds & Questions

### Round 1 – DSA (Java)
- Variation of Maximum Sum Subarray (Kadane's Algo twist)
- Valid Parentheses using Stack
- Asked to code both with and without library support
- Optimized solutions expected
- Trapping Rain Water
- Rotate-sorted array search

### Round 2 – LLD + Core Java (Time: ~60 mins)
**Design a Digital Wallet:**
- Garbage Collection and its algorithms (G1 GC, CMS)
- Multithreading concepts: locks, race conditions
- Thread Pool, String Pool
- Use of volatile and synchronized
- Difference between HashMap and ConcurrentHashMap
- Parking lot system with ticketing, payment, vehicle tracking

### Round 3 – Hiring Manager Round
- Resume walkthrough

**Situational Questions:**
- "If your manager prefers a different approach, how would you handle it?"
- Explain Dynamic Dispatch in Java
- Create a NullPointerException scenario
- Java 8 vs Java 17: Key differences in APIs and performance
- Primitive data types in Java and their sizes
- How multithreading is implemented under the hood (Runnable vs Callable, Executors)
- Use of Optional and new Stream API
- Asked to share experiences of debugging in production
- Scaling a Java application – GC tuning, thread optimizations
