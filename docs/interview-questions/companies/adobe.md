## Interview Rounds & Questions

### Round 1 – DSA + LLD
- Maximum Product Subarray
- **Modification:** Return subarray with max product
- Implement LRU Cache in O(1)
- Modify cache to plug-n-play with LRU, LFU using design patterns

### Round 2 – Java + OOPS + LLD
- Core OOPS: Abstraction, Inheritance, Polymorphism
- Difference: Interface vs Abstract Class + Implementation
- Threading: Extend Thread, Implement Runnable & Callable
- Given API contracts: Write pseudo-code for Model, Repo, Service, Controller
- SQL joins & when to use each
- Node.js internals: How server runs, HTTP protocol

### Round 3 – Managerial
- Project walkthrough & business impact (GMV etc.)
- Open source contributions?
- Use of AI in current/previous work
- Behavioral: Stakeholder alignment, contribution clarity

### Round 4 – Directorial (Most Grilling)
- MySQL → Cassandra Migration
- Differences, pros/cons, types of keys
- Mathematical internals of implemented functions
- **Question:** Design a Water Bottle 🤯
- Use encapsulation/inheritance in modeling physical objects

### Round 5 – DSA (Anagram Sentences + Tree Centers)
- **Problem 1:** Count sentences by replacing words with their anagrams
- **Problem 2:** Organizational hierarchy optimization (Tree centers)

### Round 6 – DSA + Real World System
- Product frequency tracking: Return k most viewed products
- **LLD:** Design Notification System, send via SMS, WhatsApp, Push
- Track user activity
- Discussed patterns, interfaces, extensibility
